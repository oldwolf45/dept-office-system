# T6/T7 开发契约 —— 生命周期查询 / 图表汇总

- 阶段：T6、T7（依赖 T5；并行）
- 依据：修正版 PRD §10 查询与统计
- 验收：A8（编号精确/名称模糊，含发给科室物料）、A9（按月/车间/类别汇总收支与流转数量）

## 1. 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /materials?code=&name=&status= | T6：编号精确 `=`、名称 `LIKE %..%`；含 status=issued 的科室物料 |
| GET | /materials/:id | T6：详情 + material_events 时间线（环节时间/经办人/金额） |
| GET | /stats/monthly | T7：按月 采购支出 / 处置收入 / 流转数量（issue/recycle/dispose） |

## 2. 数据来源
- 收支：purchases.amount（status=normal）按月、disposal_items.income join disposal_batches（status=normal）按月。
- 流转：material_events.action ∈ {issue,recycle,dispose} 按 occur_at 月分组计数。

## 3. 前端
- T6：MaterialListView.vue（编号精确/名称模糊/类别/状态 + 时间线抽屉）。
- T7：StatsView.vue 复用 BaseChart.vue（ECharts），双图：按月收支对比（柱）、按月流转数量（折线）。

## 4. 权限
均为读接口，仅需模块访问权。

## 5. 测试
vitest：/stats/monthly 结构（purchase/dispose/flow 数组）、材料详情含 events。前端 vue-tsc 通过。
