# T4 开发契约 —— 到货与编号（材料模块开发计划 V1.2）

- 阶段：T4（依赖 T3）
- 依据：修正版 PRD §8（到货与编号）、§5.5/§12；办公系统 PRD §14
- 验收：A5（到货后每件材料获唯一编号且不重复）

## 1. 接口（/api/materials，requireAuth + requireMaterialsAccess）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /arrivals | 到货登记：按 items 批量生成材料编号（限供应科，requireMaterialsRole('supply')） |
| GET | /materials?code=&name=&categoryId=&status= | 列表：编号精确、名称模糊、类别/状态过滤（T6 查询复用） |
| GET | /materials/:id | 详情 + 生命周期事件（material_events） |

## 2. 数据模型
复用 `materials`（软删除）：material_code(UNIQUE)、purchase_id、category_id、name、spec、unit、status(默认 in_stock)、arrived_at、created_by；`material_events`：material_id、ref_type、ref_id、action、operator_id/name、qty、amount、occur_at。

## 3. 编号规则
每件材料生成 `CL + 到货日期(YYYYMMDD) + 类别两位 + 当日四位流水`（`nextMaterialCode`，T0 已落地）。类别码取 material_categories.code（缺失按 '00'）；当日同类别流水递增，保证唯一。

## 4. 状态
到货初始 `in_stock`；每个物料写一条 `action='arrive'` 事件（ref_type='purchase'，ref_id=采购单，occur_at=到货日期）。

## 5. 权限
写动作限供应科（T10 requireMaterialsRole('supply')）；前端到货页按角色不渲染提交按钮。

## 6. 日志
`arrive_material` 写 operation_logs（含 arrivedAt、count）。

## 7. 错误码
4000（日期格式/明细空/名称空/数量≤0）、4040、4010、4030、4031、5000。

## 8. 测试
vitest：批量生成唯一 CL 编号（正则 + 去重 + in_stock）、参数校验 4000。前端 ArrivalView.vue（登记 + 编号清单可打印/抄录），vue-tsc 通过。
