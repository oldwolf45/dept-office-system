# T1 开发契约 —— 基础数据（材料模块开发计划 V1.2）

- 阶段：T1（依赖 T0；与 T2 并行；P0）
- 上位依据：修正版 PRD §12（材料类别/收支分类）、§5.1（编号）；办公系统 PRD §14
- 验收：A4（部分）

## 1. 接口清单（统一 {code:0,data,message}，均在 /api/materials 下，requireAuth + requireMaterialsAccess）

### 材料类别
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /categories | 活动列表（下拉） |
| GET | /categories/manage | 含停用（管理） |
| POST | /categories | 新增（code 两位数字可选、name 必填、同名拒绝） |
| PUT | /categories/:id | 编辑名称/排序 |
| POST | /categories/:id/disable | 停用（已用不可停用，返回 4000） |
| POST | /categories/:id/enable | 启用 |

### 收支分类
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /finance-categories | 活动列表 |
| GET | /finance-categories/manage | 含停用 |
| POST | /finance-categories | 新增（name+type，同名同类型拒绝） |
| PUT | /finance-categories/:id | 编辑 |
| POST | /finance-categories/:id/disable | 停用 |
| POST | /finance-categories/:id/enable | 启用 |

## 2. 权限矩阵（沿用 T0）
本阶段接口仅需材料模块访问权（requireMaterialsAccess）。细粒度"仅供应科可维护基础数据"的角色门禁在 T10 接入（按钮级权限），T1 暂不限制角色，便于内部初始化数据。

## 3. 数据模型
复用 T0 建的 `material_categories` / `finance_categories`（软删除）。约束：类别被 materials/purchases/plan_items 引用时不可停用（categoryInUse 校验）。

## 4. 编号规则
本阶段不涉及单据/材料编号生成（T3/T4 使用）。

## 5. 操作日志
类别/收支分类的 新增、编辑、停用 写入 operation_logs（action_type: create/update/disable_material_category、create/update/disable_finance_category），格式同办公系统 §5.16。

## 6. 错误码
沿用平台：4000 参数/业务错误、4040 不存在、4010 未登录、4030 无权限、5000 服务器错误。
