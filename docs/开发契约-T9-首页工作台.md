# T9 开发契约 —— 首页工作台

- 阶段：T9（依赖 T1~T8）
- 依据：修正版 PRD §4（首页工作台）
- 验收：A1 相关（各角色进入本角色功能入口）

## 1. 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /dashboard/overview | 流程进度（planStatus）、收支概览（purchaseAmount/disposeIncome）、待办（pendingApproval）、材料状态分布（materialByStatus） |
| GET | /me | 模块访问态 + 角色（前端按角色渲染入口，Pinia 登录态） |

## 2. 前端
MaterialsDashboardView.vue：概览卡片（待审批计划/采购支出/处置收入/在库材料）、计划状态进度标签、快捷入口、功能卡片（全部可点进，T4~T7 已完成）。角色来自 `/me`，与 Pinia 登录态一致。

## 3. 权限
读接口，仅需模块访问权。

## 4. 测试
vitest：/dashboard/overview 返回 planStatus/purchaseAmount/disposeIncome/materialByStatus。前端 vue-tsc 通过。
