# T5 开发契约 —— 领用/回收/处置（含 T8 物料账联动）

- 阶段：T5（依赖 T4）；联动部分对应 T8
- 依据：修正版 PRD §9（领用/回收/处置）、§5.1；接入管理 PRD §4（物料账联动）
- 验收：A6（领用→已领用并记录单位）、A7（回收→已回收，处置→已处置并产生收入）、A13（科室领用联动）

## 1. 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /issues | 领用（LL 编号）；限供应科 |
| POST | /recycles | 回收（issued→recycled）；限供应科 |
| POST | /disposals | 处置批次（CZ 编号，含收入）；限供应科 |
| GET | /issues?receiveUnitType=&status= | 领用记录 |
| GET | /disposals?status= | 处置批次 |
| GET | /disposals/:id | 处置批次含明细 |

## 2. 数据模型
复用 `issue_records`（issue_no UNIQUE、material_ids JSON、receive_unit_type/code/name、qty、issue_date、status）、`recycle_records`（issue_record_id、material_id、qty、recycle_date）、`disposal_batches`（disposal_no UNIQUE、total_qty、total_income、dispose_date）、`disposal_items`（disposal_batch_id、material_id、name、qty、income）、`material_events`。

## 3. 状态机（服务层 canTransitionMaterial，唯一权威）
`in_stock→[issued,recycled,disposed]`、`issued→[recycled,disposed]`、`recycled→[disposed]`、`disposed→[]`。非法流转抛 4000。

## 4. 单据编号
领用 `LL+YYYYMMDD+3位`、处置 `CZ+YYYYMMDD+3位`（nextDocNo）。

## 5. T8 物料账联动
- 领用联动：`receive_unit_type='section'`（科室）时，同库写入 `material_issues` 领用记录：material_issue_id=issue_record.id、material_codes=各材料编号、qty=领用件数（数量一致），金额口径以采购单为准。
- 计划联动：科室计划随供应科全厂汇总（T2 summaryPlans 已覆盖，A12/M5）。

## 6. 事件/日志
每件材料写 `issue/recycle/dispose` 事件（含金额）。操作日志 `issue_material`/`recycle_material`/`dispose_material`。

## 7. 错误码
4000（材料空/单位空/日期格式/非法流转）、4040、4010、4030、4031、5000。

## 8. 测试
vitest：领用→回收→处置全链路 + 状态机负例（recycled→issued 4000）+ 科室领用物料账联动数量/编号一致。前端 FlowView.vue（领用/回收/处置 Tab），vue-tsc 通过。
