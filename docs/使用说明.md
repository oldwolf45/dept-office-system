## 1. 登录与退出

### 1.1 打开系统

浏览器访问：**`https://139.196.144.92:8080`**

注意是 **https**，端口是 **8080**（不是 80、443、8443）。

第一次打开会出现「您的连接不是私密连接」之类的安全提示，这是因为系统用的是自签证书，属正常现象：

- Chrome / Edge：点「高级」→「继续前往 139.196.144.92（不安全）」
- 手机上同样点「继续访问」

浏览器地址栏出现「不安全」字样是证书问题，不影响功能使用。

### 1.2 账号密码

- **工号**：例如 `01001`
- **密码**：初次由管理员分配

工号不是姓名，也不带空格。如果记不住工号，问管理员要一张工号对照表。

### 1.3 首次登录会要求改密码

如果账号是新建或被重置过，登录后系统会强制跳转到修改密码页。新密码**至少 6 位**。

改密码也可以随时在顶部右上角进入「系统设置」→「修改本人密码」操作，需要输入原密码。

### 1.4 退出

右上角用户名 →「退出登录」。

## 2. 界面总览

### 2.1 顶部菜单 = 你有的权限

菜单**不是所有人一样**。系统在登录时按账号权限下发菜单，没权限的菜单直接不显示。

当前共 11 个菜单：

| 菜单 | 用途 | 谁能看到 |
|---|---|---|
| 工作台 | 待办、进度、提醒 | 全部 |
| 我的工作 | 登记工作、提交、查看进度 | 全部 |
| 我的物品 | 个人领用物品 | 全部 |
| 人员管理 | 账号维护、层级调整 | 层级 ≥ 2 |
| 科室记账 | 科室物料账与经费 | 层级 ≥ 2 / 记账员 / 有效代录人 |
| 月度报表 | 生成月度汇总表 | 同上 |
| 汇总统计 | 数据统计图表 | 全部 |
| 总结与PPT | 月度总结与汇报材料 | 全部 |
| 汇总经验库 | 经验条目检索 | 层级 ≥ 2 / 记账员 |
| **材料管理** | **材料全生命周期（本次新增）** | **有模块访问权** |
| 系统设置 | 改密码、字典维护、备份恢复 | 全部（**内容分权限**，见 9.2） |

**看不到某个菜单 = 该账号没有这个权限**，不是系统故障。找管理员开。

### 2.2 材料管理是独立工作台

点顶部「材料管理」进的是材料模块自己的工作台，不回办公系统工作台。两个模块并列，点顶部菜单来回切。

手机端底部导航会自动收纳常用入口。

## 3. 材料管理：第一次使用先配角色

这一步不配，后面所有功能都点不动。**管理员先做，其他人可跳过本节。**

### 3.1 为什么必须先配角色

材料模块的权限分两层，很容易搞混：

- **平台层级**（1-5）：决定你能不能**进**这个模块、能不能看到「角色配置」页
- **材料模块角色**：决定你进来之后**能干什么**

关键点：**层级高不等于能操作材料**。层级 5 的科长如果没被授予「车间主任 / 供应科」角色，一样不能审核计划、不能登记采购——这是设计如此，不是 bug。

### 3.2 怎么配

路径：**材料管理 → 工作台 → 角色配置**（只有层级 ≥ 3 才显示这张卡片）

1. **人员**：下拉里按工号或姓名搜索，选项显示「工号 姓名（L层级｜科室）」
2. **材料模块角色**：工段长 / 车间主任 / 供应科 / 科室经办
3. **单位类型**：车间/工段，或科室
4. **单位名称**：可从下拉选现有科室，也可以**直接输入**（比如「一车间」「二号工段」——车间工段目前不在账号的科室字段里，需要手填）
5. 点「授予」

已授列表按人聚合，一人多角色会并列显示。**标签上的 × 就是撤销**，会二次确认。

### 3.3 四个角色分别能干什么

| 角色 | 能做的操作 |
|---|---|
| 工段长 | 填报车间类需求计划 |
| 车间主任 | 审核/驳回计划 |
| 供应科 | 审核/驳回计划、登记采购、登记到货、登记领用/回收/处置 |
| 科室经办 | 填报科室类需求计划 |

一条经验：**供应科和车间主任至少各配一人**，否则计划批不下去、料发不出来。

### 3.4 一人多角色是允许的

同一个人可以既是车间主任又是供应科，也可以既是工段长又是科室经办。分别授予即可。

但**同一个人同一个角色不能重复授予**，系统会提示「已具有该角色」。

## 4. 材料管理：日常操作

### 4.1 一张图看全流程

```
需求计划(车间/科室填报) → 审核(车间主任/供应科)
        ↓ 通过
    采购登记(供应科)  ── 记金额、供应商、经手人
        ↓
   到货登记 → 自动生成材料编号 → 材料进入「在库」
        ↓
   ┌────┴────┬──────────┐
 领用       回收        处置
(科室/车间) (退回来)   (报废/变卖，记收入)
   ↓
 科室领用会同步写入「科室记账 → 物料账」
```

材料的状态只会单向往前走：

```
在库 → 已领用 → 已回收 → 已处置
  └──────┴────────┘（在库/已领用都可直接处置）
```

**不能倒着走**。已经处置的材料不能再领用。

### 4.2 工作台

进「材料管理」看到的首页：

- 四张概览卡：待审批计划、采购支出合计、处置收入合计、在库材料
- 计划流程状态：草稿 / 已提交 / 已通过 / 已驳回 各多少条
- 右下角是功能入口卡片（角色配置只有层级 ≥ 3 才出现）

右上角标签显示**你自己**的材料角色，如果显示「未分配材料模块角色」，说明管理员还没给你配。

### 4.3 基础数据（先配，后录单）

这两个是下拉框的数据来源，**建议系统启用后第一时间配好**。

**材料类别** —— 路径：工作台 → 材料类别

| 字段 | 说明 |
|---|---|
| 类别码 | 两位数字，如 `01`、`05`。**留空自动分配**。这个码会进材料编号 |
| 名称 | 如「钢材」「电气件」 |
| 排序 | 数字小的排前面 |

类别一旦被材料使用过就**不能停用**，只能改名。停用后不再出现在下拉框里。

**收支分类** —— 路径：工作台 → 收支分类

分支出类和收入类，系统自带 3 条种子数据。采购登记时选「支出类」，处置登记时对应收入。

### 4.4 需求计划

路径：工作台 → 需求计划

**填报（工段长 / 科室经办）**

1. 点「新增计划」
2. 选**月份**、**类型**（车间 / 科室）
3. 填**单位编码**和**单位名称**
4. 加明细，每行填：物料名称、类别、计划数、参考单价（金额自动算）
5. 「保存」→ 生成**草稿**，单据号形如 `JH20261101001`

草稿可以反复改。确认无误后点「提交」，状态变成**已提交**，此时不能再改。

**审核（车间主任 / 供应科）**

在列表里找到「已提交」的单据，点「查看」进详情：

- 点「通过」→ 状态变**已通过**
- 点「驳回」→ 必须填写驳回意见，状态变**已驳回**，填报人能看到意见后重新提交

**汇总**：页面上的「全厂汇总」按单位聚合各月计划的填报数、通过数、驳回数。

### 4.5 采购管理

路径：工作台 → 采购管理（需要「供应科」角色）

点「登记采购」，填：

| 字段 | 必填 | 说明 |
|---|---|---|
| 摘要 | 是 | 采购物品说明 |
| 金额 | 是 | 不能为负数 |
| 采购日期 | 是 | 格式 YYYY-MM-DD，选择器里选 |
| 材料类别 | 否 | |
| 收支分类 | 否 | 选支出类 |
| 供应商 | 否 | |
| 经手人 | 否 | |

保存后单据号形如 `CG20261101001`。

**作废**：只有「正常」状态能作废，且**必须填写作废意见**。作废后记录保留，不计入支出合计。

查询支持按月份、材料类别、状态筛选。

### 4.6 到货登记与材料编号

路径：工作台 → 到货登记（需要「供应科」角色）

**这是材料真正进入系统的环节。**到货登记完，材料才存在，才会有编号。

1. 选**到货日期**
2. 可填**关联采购单 ID**（把到货挂到某笔采购上，便于对账；可选）
3. 选**材料类别**
4. 加明细，每行：名称、规格、单位、数量
5. 点「生成编号并入库」

系统会：

- 为**每一个**材料生成唯一编号，规则见[附录](#10-附录编号规则与状态机)
- 材料状态置为**在库**
- 自动写一条「到货入库」流转记录

**打印/抄录**：入库后点「打印/抄录」，会弹出本次生成的全部编号，可以打印或复制。**建议贴在实物标签上**——后续领用、回收、处置都靠编号定位材料。

注意事项：

- 到货日期格式必须是 `YYYY-MM-DD`
- 明细至少一条，每条数量必须大于 0
- 类别决定编号里的两位类别码，类别没配的话会落到 `00`

### 4.7 领用 / 回收 / 处置

路径：工作台 → 领用/回收/处置（需要「供应科」角色）

页面分三个页签。

**领用**

1. 从「在库材料」里选材料，**可以多选**（下拉显示「编号 名称」）
2. 填**领用单位**（编码 + 名称）
3. 填**经办人**、**领用日期**
4. 点「登记领用」

结果：材料状态变**已领用**，生成领用单号 `LL20261101001`，并写一条流转记录。

**科室领用会同步进「科室记账 → 物料账」**（单位类型选「科室」时），金额和数量与材料模块一致。车间领用不写物料账。

**回收**

选「已领用」的材料，填经办人和回收日期，点「登记回收」。状态变**已回收**。

回收不生成单据号，直接记在流转记录里。

**处置**

1. 选处置材料：**在库、已领用、已回收**的都可以（报废库存不用先领用）
2. 填**处置方式**（如「报废」「变卖」）、**经办人**、**处置日期**
3. 明细每行填数量和**收入**金额
4. 点「登记处置」

结果：状态变**已处置**，生成处置批次号 `CZ20261101001`。收入会进入工作台的「处置收入合计」和图表汇总。

**处置是终态**，之后这条材料不能再有任何动作。

### 4.8 生命周期查询

路径：工作台 → 生命周期

- **材料编号**：精确匹配，适合知道编号时查
- **名称**：模糊匹配，适合只记得叫什么

点「时间线」看这条材料的完整履历：什么时候到货、谁经办、什么时候被谁领走、最后怎么处置的，一条不落。

这是这套系统最有用的功能之一——**任何一件材料都能倒查到底**。

### 4.9 图表汇总

路径：工作台 → 图表汇总

按月展示三类数据：

- 采购支出（按月）
- 处置收入（按月）
- 流转数量（按月、按动作）

用于看趋势和对账。

## 6. 权限：两层机制怎么理解

这是最容易踩坑的地方，单独说清楚。

### 6.1 两层权限

| 层 | 是什么 | 谁管 | 决定什么 |
|---|---|---|---|
| 平台层级 | 1-5 级的行政层级 | 人员管理 | 能不能进模块、能不能管人、能不能配角色 |
| 模块访问权 | 有没有「材料管理」这个菜单 | 平台（默认开放） | 能不能进材料模块 |
| 材料模块角色 | 工段长/车间主任/供应科/科室经办 | 材料模块 → 角色配置 | 进来之后能点哪些按钮 |

### 6.2 按钮看不到，按这个顺序排查

1. **菜单里有没有「材料管理」** → 没有：缺模块访问权
2. **右上角角色标签显示什么** → 显示「未分配材料模块角色」：去角色配置授予
3. **角色对不对** → 比如想登记采购，必须是「供应科」角色
4. **单据状态对不对** → 比如「通过」按钮只在「已提交」状态出现

### 6.3 前端隐藏 + 后端拦截

前端只是把没权限的按钮**不渲染**，真正的拦截在后端。就算绕过界面直接调接口，后端照样拒绝并返回错误码。

## 7. 常见问题

**Q：网页打不开，一直在转圈或提示无法访问**

1. 确认地址是 `https://139.196.144.92:8080`，**https** 且端口 **8080**
2. 公司网络如果限制外网端口，用手机流量试一下
3. 提示证书错误 → 点「高级」→「继续前往」，这是自签证书的正常提示

**Q：提示「工号或密码错误」**

工号是纯数字编号（如 `01001`），不是姓名。确认大小写和输入法没串。连续错 5 次会在登录日志里标红，需要管理员关注。

**Q：提示「账号已停用，禁止登录」**

账号被管理员停用了，联系管理员。

**Q：忘记密码了怎么办**

系统目前**没有自助找回，也没有管理界面重置**。需要系统管理员在服务器侧重置密码。建议尽快找管理员处理，同时这也是个待补的功能（见文末「已知缺口」）。

**Q：登录后菜单里没有「材料管理」**

该账号没有被授予材料模块访问权。当前配置是「默认开放」——只要没做限制，所有人都有；如果管理员开始按人授权，没在名单里的人就看不到。

**Q：进了材料管理，但一个操作按钮都没有**

99% 是没配材料模块角色。右上角如果显示「未分配材料模块角色」，让层级 ≥ 3 的同事在「角色配置」里授予。

**Q：点操作提示「当前角色无权执行该操作」**

角色不匹配。比如登记采购要「供应科」，审核计划要「车间主任」或「供应科」。

**Q：点操作提示「系统维护中，请稍后」**

正在做数据恢复，系统临时锁定写入。等几分钟重试。

**Q：单据号上的日期和我填的业务日期不一样**

单据号里的日期取的是**开单当天**，不是你填的业务日期。比如今天补录一张 10 月 15 日的采购单，单号还是今天的日期。这是设计如此。

**Q：材料编号怎么读**

`CL` + 到货日期 8 位 + 类别码 2 位 + 当日流水 4 位。
例：`CL202611010101` = 材料 · 2026-11-01 到货 · 类别 01 · 当天第 1 件。

**Q：历史记录的时间比实际早 8 小时**

v1.1.1 之前部署的容器时区是 UTC，导致早期数据时间戳偏早 8 小时。该问题已修复，**新产生的数据时间正确**，历史数据未做批量修正（量很小）。看到旧记录时间不对属已知情况。

## 8. 错误码对照

界面上的报错会直接显示中文，这里是给排查用的对照表。

| 错误码 | 含义 | 怎么办 |
|---|---|---|
| 4000 | 参数或业务校验不通过 | 看提示文字，通常是必填项没填、格式不对、状态不允许 |
| 4010 | 未登录 / 登录过期 / 账号停用 | 重新登录；若提示停用找管理员 |
| 4030 | 无权限访问 | 缺模块访问权，或层级不够 |
| 4031 | 当前角色无权执行该操作 | 缺材料模块角色，去角色配置授予 |
| 4040 | 记录不存在 | 数据可能已被删除或撤销 |
| 5030 | 系统维护中 | 正在做数据恢复，稍后重试 |
| 5000 | 服务器内部错误 | 记录操作时间，反馈给管理员查日志 |

## 9. 管理员：备份与恢复

### 9.1 自动备份

系统每天凌晨 **3:00–4:00** 自动备份一次，保留最近 **7 份**。备份文件在服务器的 `data/backups/` 目录。

如果某天自动备份失败，工作台会出现提醒，不要忽略。

### 9.2 手动备份

**入口在哪：系统设置 → 备份恢复面板。**

注意一个容易踩的坑：备份面板**只对层级 3（科长）的账号渲染**。层级 4、5 的账号进「系统设置」看不到这块内容——这是平台原有约定（备份由科长负责），不是故障。

如果当前登录的账号看不到备份面板，换一个科长的账号登录，或让科长来操作。

点「立即备份」生成一个 ZIP，包含：

- 数据库文件（`db/app.db`）
- 附件目录（未删除的附件）
- 配置项（非敏感，白名单）
- `manifest.json` 清单（每个文件的 SHA-256 校验值 + 各表记录数）

备份文件可在页面上**下载**保存到本地，建议定期下载一份异地留存。

### 9.3 恢复（危险操作）

**入口：系统设置 → 备份恢复面板（同样只有层级 3 账号可见）→ 上传恢复**

流程是两段式，第二步必须输入确认语：

1. **上传并预览** —— 系统校验 ZIP、逐文件比对 SHA-256、检查系统版本与库结构版本，**这一步不动任何数据**
2. 看清楚预览里的备份时间、系统版本、各表记录数
3. **确认恢复** —— 必须手动输入「**覆盖当前数据**」四个字，才会执行

点确认后系统会：

1. 先给当前数据打一份临时备份（回滚网，存在 `data/restore-tmp/`）
2. 加维护锁（期间别人写入会被拒绝，返回 5030）
3. 解压 → 整体替换数据库和附件 → 重新打开数据库
4. 对照清单逐表校验记录数，把对不上的列出来
5. 释放维护锁
6. **失败会自动回滚**到恢复前状态，并提示原因

**恢复完成后所有人需要重新登录。**

### 9.4 几条硬规矩

- 恢复前先手动备份一次，别依赖系统自动备份
- 恢复期间通知大家别操作系统
- 恢复后抽查几条关键数据（用户数、当月单据、材料编号能不能查到）
- 备份 ZIP 别用压缩软件改，SHA-256 一改就校验不过

### 9.5 部署相关（技术同事看）

| 项 | 值 |
|---|---|
| 部署目录 | `/opt/legacy-office` |
| 数据目录 | `data/`（容器内 `/app/data`） |
| 访问端口 | 宿主 `8080` → 容器 `443`（HTTPS） |
| 时区 | 容器已注入 `TZ=Asia/Shanghai` |
| 发行模式 | `DISTRIBUTION_MODE=1`（不预置种子账号） |

## 10. 附录：编号规则与状态机

### 10.1 编号规则

| 类型 | 前缀 | 格式 | 示例 |
|---|---|---|---|
| 需求计划 | JH | JH + 年月日 + 3 位流水 | `JH20261101001` |
| 采购单 | CG | CG + 年月日 + 3 位流水 | `CG20261101001` |
| 领用单 | LL | LL + 年月日 + 3 位流水 | `LL20261101001` |
| 处置批次 | CZ | CZ + 年月日 + 3 位流水 | `CZ20261101001` |
| 材料编号 | CL | CL + 到货日 + 类别 2 位 + 当日 4 位 | `CL202611010101` |

回收不生成单据号。

日期取**开单当天**（服务器时间，北京时间）。

### 10.2 材料状态机

| 当前状态 | 可以变成 | 不可以 |
|---|---|---|
| 在库 | 已领用 / 已回收 / 已处置 | — |
| 已领用 | 已回收 / 已处置 | 回到在库 |
| 已回收 | 已处置 | 回到在库、再领用 |
| 已处置 | 无（终态） | 任何操作 |

### 10.3 计划状态机

| 当前状态 | 可以变成 | 谁操作 |
|---|---|---|
| 草稿 | 已提交 | 填报人 |
| 已提交 | 已通过 / 已驳回 | 车间主任 / 供应科 |
| 已驳回 | （重新提交后回到已提交） | 填报人改完后提交 |
| 已通过 | 无（终态） | — |

驳回必须填意见，意见会展示在计划详情里。

## 已知缺口

以下是目前**确实没有**的功能，先写在这里，避免大家找半天：

1. **密码重置** —— 没有自助找回，也没有管理界面重置，只能服务器侧处理
2. **材料模块访问权的界面管理** —— 当前是「默认开放」，还没做按人开通/关闭的界面
3. **车间/工段组织数据** —— 账号里只有科室字段，「一车间」「二号工段」这类单位需要在角色配置里手工输入
4. **回收单打印** —— 回收不生成单据号，没有打印入口
5. **备份面板的权限口径不一致** —— 前端只给层级 3（科长）渲染界面，后端接口却是 `层级 ≥ 3` 都放行。结果是层级 4、5 的账号有接口权限但看不到界面。建议后续统一

有问题或需要补功能，直接找系统管理员反馈。
